# Ali Abdaal · 具体知识的学习与练习方法说明

## 适用问题

- 学技能
- 复习
- 考试
- 练习

## 核心原则

- 知识库学习地图与具体技能学习分开
- 用表现而非阅读时长检验学习

## 标准步骤

1. 定义可展示的能力
2. 安排提取、应用和反馈练习
3. 根据错误调整复习间隔
4. 完成真实测验或作品

## 应交付的结果

- 技能学习计划
- 练习安排
- 检验方法
